# NatureQuery documentation

Documentation is grouped by purpose so active guidance is easy to distinguish from historical material.

## Maintained guides

- [Getting started](getting-started.md) - local setup, validation, and common commands.
- [Architecture](architecture.md) - system boundaries and request flows.
- [Database testing](operations/database-testing.md) - local database test environments.
- [Desktop companion](../desktop/README.md) - Electron architecture and development.
- [Desktop releases](../desktop/RELEASE.md) - packaging and release procedure.
- [Provenance](provenance.md) - authorship and third-party material policy.

## Internal and historical material

- `internal/` contains private technical context that should be reviewed before sharing.
- `audits/` contains point-in-time assessments. Findings may no longer describe the current code.
- `archive/` contains superseded guides retained for project history.

When a guide becomes obsolete, move it to `archive/` with a date or clear legacy name instead of leaving competing instructions at the repository root.
